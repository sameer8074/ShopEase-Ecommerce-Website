
# ShopEase - E-Commerce Website 🛍️

ShopEase is a modern and responsive e-commerce website developed using HTML, CSS, and JavaScript.

The project provides users with a smooth shopping experience through product browsing, search, category filtering, wishlist management, cart functionality, and a checkout interface.

## 🚀 Live Demo

[View ShopEase Live Website](YOUR-GITHUB-PAGES-URL)

## 📌 Features

- Responsive e-commerce website design
- Product listing and product cards
- Product search functionality
- Category filtering
- Product details modal
- Related products section
- Add to cart functionality
- Cart quantity management
- Remove products from cart
- Clear cart functionality
- Local storage cart persistence
- Wishlist functionality
- Checkout interface
- Dedicated About page
- Dedicated Contact page
- Responsive design for mobile and desktop devices

## 🛠️ Technologies Used

- HTML5
- CSS3

- Local Storage
